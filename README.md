# 🔐 Key Password Manager

A simple local password manager that securely encrypts and stores your passwords.

## 🚀 Features
- Encrypts passwords with the `cryptography` library  
- Stores credentials locally in `passwords.json`  
- Allows you to add and retrieve passwords securely  

## ⚙️ Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Elybk/key-password-manager.git

2.Install dependencies:

pip install -r requirements.txt


3.Run the app:

python main.py

⚠️ Security

Your encryption key (key.key) is stored locally — don’t share it!

This tool is for personal/local use only.
